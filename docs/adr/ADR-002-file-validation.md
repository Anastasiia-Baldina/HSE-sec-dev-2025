# ADR-002: Валидация загрузок файлов

Дата: 2025-10-15
Статус: Accepted

## Context
Для stretch-функциональности импорта CSV необходимо безопасно обрабатывать загружаемые файлы. Риски включают переполнение памяти, path traversal и загрузку вредоносных файлов.

## Decision
Реализовать многоуровневую валидацию загружаемых файлов:
- Проверка MIME type (только text/csv)
- Ограничение размера (5 MB максимум)
- Проверка magic bytes для CSV
- Безопасное сохранение с UUID именами
- Запрет симлинков в путях

## Alternatives
1. **Trust user input** - неприемлемо по соображениям безопасности
2. **Внешние валидаторы** - избыточно для текущих требований
3. **Базовая валидация** - недостаточно для защиты от сложных атак

## Consequences
**Плюсы:**
- Защита от распространённых атак на загрузку файлов
- Соответствие NFR-10
- Предсказуемое поведение системы

**Минусы:**
- Дополнительная обработка каждого файла
- Возможные false positives при валидации

## Security Impact
Защищает от атак через загружаемые файлы, снижает риски R2 и R11. Соответствует NFR-10.

## Rollout Plan
1. Реализовать валидацию в endpoint импорта
2. Добавить тесты для граничных случаев
3. Настроить мониторинг rejected uploads
