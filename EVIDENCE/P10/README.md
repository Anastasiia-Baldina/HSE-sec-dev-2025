# P10 - SAST & Secrets Evidence

This directory contains evidence for Practice 10: Static Application Security Testing (SAST) and Secrets Scanning.

## Files

### `semgrep.sarif`
- **Format**: SARIF (Static Analysis Results Interchange Format)
- **Generated by**: Semgrep
- **Contents**: Code security and quality findings
- **Scanned with**:
  - Semgrep p/ci profile (CI-optimized rules)
  - Custom rules from `security/semgrep/rules.yml`
- **Usage**:
  - View in GitHub Code Scanning
  - Import into SAST tools
  - Track security findings over time

### `gitleaks.json`
- **Format**: JSON
- **Generated by**: Gitleaks
- **Contents**: Potential secrets and credentials found in code
- **Configuration**: `security/.gitleaks.toml`
- **Includes**: File paths, line numbers, rule matches

### `sast_summary.md`
- **Format**: Markdown
- **Generated by**: Workflow script
- **Contents**: Human-readable summary of findings
- **Includes**:
  - Scan configuration details
  - Finding statistics (counts by severity)
  - Top issues
  - Next steps and recommendations

## How to Use

### Viewing SAST Results
1. **GitHub Code Scanning**: Results are automatically uploaded
2. **Local viewing**: Use SARIF viewers or text editors
3. **Command line**:
   ```bash
   # Count findings
   jq '.runs[0].results | length' semgrep.sarif

   # List all findings
   jq -r '.runs[0].results[] | "\(.level): \(.ruleId) - \(.message.text)"' semgrep.sarif
