# P09 - SBOM & SCA Evidence

This directory contains evidence for Practice 09: Software Bill of Materials (SBOM) and Software Composition Analysis (SCA).

## Files

### `sbom.json`
- **Format**: CycloneDX JSON
- **Generated by**: Syft
- **Contents**: Complete inventory of all software components (dependencies) in the project
- **Usage**:
  - Dependency tracking
  - License compliance
  - Security audits
  - Supply chain transparency

### `sca_report.json`
- **Format**: JSON
- **Generated by**: Grype
- **Contents**: Vulnerability scan results against known CVEs
- **Fields**:
  - `matches[]`: Array of vulnerability matches
  - `vulnerability`: CVE details (ID, severity, description)
  - `artifact`: Affected package (name, version, type)

### `sca_summary.md`
- **Format**: Markdown
- **Generated by**: Custom script in workflow
- **Contents**: Human-readable summary of vulnerabilities
- **Includes**:
  - Severity statistics (Critical/High/Medium/Low)
  - Top vulnerabilities list
  - Instructions for further analysis

## How to Use

### Viewing Results
1. Download artifacts from GitHub Actions
2. Explore with `jq`:
   ```bash
   # Count vulnerabilities by severity
   jq '[.matches[].vulnerability.severity] | group_by(.) | map({(.[0]): length}) | add' sca_report.json

   # List all CVEs
   jq '.matches[] | "\(.vulnerability.id): \(.artifact.name)@\(.artifact.version) (\(.vulnerability.severity))"' sca_report.json
